# Study Chinese in China - Official Website

This is the official website for promoting Chinese language study in China, providing comprehensive study abroad information and services.



## Technology Stack

- HTML5
- CSS3 (Modern Responsive Design)
- JavaScript (Interactive Features)
- Responsive Design, Mobile-Friendly

## Project Structure

```
LensTalk/
├── index.html          # Main page
├── css/               # Style files
│   ├── style.css      # Main styles
│   └── responsive.css # Responsive styles
├── js/                # JavaScript files
│   └── main.js       # Main functionality
├── images/            # Image resources
└── README.md          # Project description
```

## Usage

1. Open `index.html` directly in a browser
2. Or run the project using a local server

## Page Structure

- **Programs**: Study program information
- **Locations**: Study location options
- **Community**: Community exchange
- **Admission**: Application process
- **About**: About us
- **Apply Now**: Apply now button
